# Data-driven stage builder (`tools/stage/`)

A video made from data only: instead of one `tools/blender/<slug>.py` per video, each script scene carries the
`stage` field and Blender builds everything from ready-made pieces (CC0, from `assets/`).

If `tools/blender/<slug>.py` exists, it takes precedence (old videos do not change). Without it, and with `stage` in **all** scenes,
`python -m ifscape blender scripts/<slug>.json` uses `tools/stage/stage_main.py`.

## Files
| File | Role |
| --- | --- |
| `catalog.json` | 832 measured models (type, size, polygons, animations); generated by `catalog_scan.py` |
| `catalog_scan.py` | scans `assets/` in Blender and rewrites the catalog (`blender -b -P tools/stage/catalog_scan.py`, ~15 s) |
| `sheet.py` | showcase: grid of models with the id underneath (`blender -b -P tools/stage/sheet.py -- <folder> tree,rock --pack quaternius/`) |
| `models.py` | catalog in Blender: static = light instance (shared mesh), with skeleton = `rigs.py` |
| `presets.py` | stages (`SETS`), lights (`LIGHTS`), ground with hills, sky dome, automatic dressing out to the horizon |
| `cameras.py` | POV, static, dolly_in/out, truck, orbit, crane, macro; impact shake; hard cut between scenes |
| `build.py` | reads `stage` and builds: props, layouts, walks, word cues, camera, checks |
| `validate.py` | checks `stage` when the script loads (clear error, with "did you mean…") |
| `stage_main.py` | Blender entry point |
| `ant.py` | ant with skeleton and actions (`ant`) and anthill (`anthill`) made in code |
| `procedural.py` | pieces made in code (`boat`, `gull`, `ice`), the fisherman kit (rod, line, bucket, gestures) and the `ocean` stage (water, pier, islands, buoys, lamp posts) |
| `procedural_items.py` | catalog entries for those pieces (`catalog_scan.py` adds them) |

## The `stage` field (per scene; meters; x right, y depth, z up)
```json
"stage": {
  "set": "savanna", "light": "dry-noon",
  "props": [
    {"id": "trex", "name": "rex", "at": [0, 18], "len": 12, "action": "Idle"},
    {"id": "zebra", "name": "herd", "layout": "herd", "n": 14, "at": [0, 30], "spread": 12, "to": [-10, 30], "len": 2.3},
    {"kind": "tree", "pack": "quaternius/stylized-nature", "layout": "scatter", "n": 20, "area": [0, 30, 15], "h": [8, 12]}
  ],
  "camera": {"preset": "dolly_in", "at": [0, -2], "look": "rex", "dist": 6, "lens": 24},
  "cues": [{"word": "roars", "do": "shake", "amp": 0.15}, {"word": "gone", "do": "vanish", "target": "herd"}]
}
```
- **set:** `meadow`, `savanna`, `forest`, `desert`, `vacuo`, `ocean`, or `same` (continues the stage; with `light`, the light state changes
  AT THE CUT, for time jumps; inside the scene, only through the `light` cue). **light:** `noon`, `dawn`, `dusk`, `night`, `overcast`, `dry-noon`.
- **props:** `id` (catalog model, or a list) or `kind` (randomly drawn type; `pack`, `tag`, `season` filter). Without `season`, no autumn,
  snow, `twistedtree` (red leaves) or `plant-7` (purple) comes out. `h` = height (people, plants, trees), `len` = length (animals). Both
  are measured on the model. `name` lets cameras and cues refer to it.
- **layout:** `single` (default with n=1), `scatter` (default with n>1), `herd`, `line`, `ring`, `grid`.
- **walking:** `to` [x,y] or `path` [[x,y],...] with `speed` (m/s), `wait` (s before leaving), `action` (`Walk`, `Run`...). The camera follows the target.
- **camera:** `look` is a piece name (`herd` or `herd0`) or `[x,y,z]`. The target must stay in the 9:16 safe area (automatic check).
  `preset: "path"` goes through points `path: [{t|frac, at, z, look, lens}]` (smooth curve); `{"t": 0, "prev": true}` starts where the previous
  scene's camera ended (continuous shot across blocks).
- **cues:** `word` (+ `nth`, `off`) uses the voice timing (`kit.W`); without voice, it falls back to `t` (s) or `frac`. `do`: `pop`, `vanish`, `move` (`to`, `dur`),
  `action` (`action`), `shake` (`amp`), `light` (`light` = name, `dur` s: the light drifts slowly there), `grow` (`from` 0.05, `size` 1, `dur`, `stagger`:
  growing scale, each target starts up to `stagger` s later).
- **fact** (scene field, not part of `stage`): card `{value, text, t, dur, source?}` under the question, only with `panel_style: "hud"`. The source does not appear
  in the video.
- **Sound by rule** (`ifscape/sfx.py::_stage_cues`, turns on by itself with `stage`; `"sfx_auto": false` turns it off): ambience per stage (one layer per `same` group),
  footsteps (animal: `hooves`, dino: `rumble`) when the piece walks, `hit` on `shake`, `whoosh` on `vanish` and `dust`, `plop` on `pop`, `light_sweep` on `light`.

## Fluid movement (rule: "always fluid animation, loosen up as much as possible")
- **Nothing skates:** the step is calibrated by each skeleton's planted foot (`models.feet_of` + `rigs.planted_speed`). `speed` (m/s) or `rate` only choose the gait cadence (0.45x to 1.8x of the natural one). **A small animal walks with the `Run` action** (the mouse's `Walk` gives 0.05 m/s: it would "row" in place). `build.py` prints "step: planted foot X m/s, cadence Yx".
- **Living piece, no restart:** `span: "group"` or `[scene_a, scene_b]` makes the piece exist and move across several scenes (declare it in the first; the following ones cite the name in the camera and in cues). `loop: true` goes back and forth along the `path` until the end of the span. A piece standing in Idle for 60 s is what makes it "stiff": give it a path.
- **Camera follows the witness:** `look: "witness^1.0"` looks 1.0 m above the piece's foot (the mouse falls in the bottom third, out of the caption strip). The `path` preset with `prev: true` gives the continuous shot across scenes.
- **Cues:** `light` (slow light), `grow` (scale, with `stagger`), `meteor` (fireball with a tail), `move` with [x,y,z], `action`, `shake`, `pop`, `vanish`, `dust`, `react`.
- **`react` (whoever is seated reacts):** `{"do": "react", "target": "witness", "t": 5.2, "look": "first",
  "look_z": 0.25, "turn": 0.5, "lean": -10, "snap": 0.3, "hold": 1.5, "back": 2.0}`. Additive layer (NLA COMBINE) over the
  pose (`Sitting`), on the Head, Neck, Torso and Abdomen bones (Quaternius people skeleton). `look`: piece name (looks
  `look_z` m above the foot; default half the height), `[x, y, z]`, `"front"`/`null` (back to the front) or `"keep"`; turns in
  `turn` s (≤ 0.6 s: fast with a slight overshoot; more: smooth; 0 = already looking). The head leads, the neck follows 2 and the
  torso 5 frames later; max turn ±75°. `lean` degrees (negative = backward, -25 to 20) in `snap` s; with `hold` it returns to 0
  in `back` s, without `hold` it stays (the next `react` starts from where it is). While looking, the gaze wanders ±2.5° and the chest
  breathes (they vanish on the 1st and last frame, for the loop closing). Use where the piece is SEEN: in the ants POV the witness
  only enters the frame at ~f150.
- **`dust` (impact dust that reaches the lens):** `{"do": "dust", "target": "first", "t": 3.4}` on the frame where the body
  hits the ground. ~40 clouds with a soft edge and a slightly translucent core (dry earth `#CDBB98`, no shadow, BLENDED, no
  particles) come out small from the base of the piece, roll along the ground toward the camera up to `reach` of the distance (default 0.55;
  max 0.6), rise and spread, and fade out becoming transparent until ~2.9 s. `size` scales the clouds (1 = proportional to the piece's `len`),
  `n` changes the number. Automatic sound: `whoosh` with the peak 0.45 s after the impact (add a `shake` at the same `t`
  for the `hit`). Cost: ~0 s/frame extra (3 shared meshes).
- **A place with air:** world color follows the sky of the hour; distance mist (Mist, 20 to 350 m, up to 45%, off the sky); ground by vertex with a gradient; instances with their own scale, tilt and tone; dense grass near the camera.
- **Automatic checks:** camera target in the safe area and out of the caption strip; `anim_audit.py` and `jitter.py --step` after the render (the terrain's "× ground" is a false positive). Dressing (tree, bush) does not spawn in the walker's corridor.

## `ocean` stage (oceans-no-salt)
- Camera at [0, 0] looking +y: wooden pier from x -1.2 to 1.6 and y -49 to 5.2, top at z = 0; water at z = -0.8 out to 1,700 m
  (Geometry Nodes waves that fade with distance: no shimmer); beach and hills behind (y < -42), islands on the horizon,
  3 buoys and 2 boats far away; 3 posts on the left side of the pier that light up only with `light: night` (`LIGHTS[...]['lamp']`).
- `ground_height` becomes: pier top, water or beach. Anyone standing on the ice uses `"z": 0.07`.
- **Pieces:** `boat` (4 m dinghy; `len` = hull; lying along the pier by default, tied to the end posts, rocks;
  the water disappears inside the hull), `gull` (circles at 3-5 m, glides, dives once with a splash and comes back with nothing),
  `ice` (plates in rings around the fishing hole at `at`, nothing crosses pier or boat; `span` to last).
- **Fisherman:** `"rod": 2.6` (standing) or `0.85` (seated, `"action": "Sitting"` holds the pose and the overturned bucket becomes a stool).
  Standing, the free hand stays on the camera side; the line cannot fall on the pier (check). Gestures by `action`: `drink`, `cast`, `bite`.
- **New cues:** `still` (what floats stops rocking), `water` (`color` hex, `dur`: the sea color drifts slowly; the ice
  takes 28% of it), `grow` on `ice` with `keep` (m already frozen at the cut) and `stagger` (s to close the rest, from near to
  far); what floats inside the ice locks on its own.
- **Gestures and cues, 2nd round:** `drink` with a tin mug (comes out of the bucket, sip with the face turned to the camera,
  2nd sip ~9 s later, goes back to the bucket); `cast` accepts `to` [x, y] (where the float lands); `bite` bends the rod tip;
  `drill` (seated on the ice: auger, shavings, the hole only opens there); `dive` cue on a gull (`"dive": "cue"` on the prop waits for the
  cue; `"dive": "here"` touches the water at `at`; `radius`, `alt`; `stagger` on the cue); prop `"carry": true` (rod and empty
  bucket in hand when walking). `dusk` light has a cold fill (`fill`). Under the ice the waves stop at the cut.
- **Redeclared piece:** with a live `span`, repeating the piece at the same `at`, without walking or changing action, is just a citation; if it changes,
  the old one leaves at the cut and the new one enters.

## `ant` and `anthill` pieces (ants-human-size; code in `ant.py`)
- **`ant`** (kind `insect`, with its own skeleton made in code; shared mesh, armature and actions, 1,416 tris):
  `len` = head to the end of the gaster in m (default 1.7; a common ant 0.01 to 0.012). Standing still, the height is ~0.3 x `len`
  (0.5 m on the 1.7 one); raised (`Rise`), ~0.55 x `len` (~0.95 m). Spread legs take up ~1.25 x `len` of width: in
  a line, ants that will grow to 1.7 m need ~2.3 m between them.
- **Actions:** `Idle` (antennae, gaster breathing), `Walk` (tripod; planted foot 0.45 x `len` m/s), `Run` (1.45 x `len` m/s:
  use on the small ant, e.g. 0.02 m/s with `len` 0.012). Once only, holding the final pose: `Rise` (4 s), `Tremble`
  (1 s, only after `Rise`), `Sag` (3.8 s, too much weight: the legs tremble and give way
  slowly, the left side first; the body falls in 0.7 s with the feet sliding outward, the gaster bounces ~2.5 cm and the
  legs settle; without a `Rise` before, it starts from the normal pose on its own). `SagIdle`: lying down in a 3 s loop (antennae
  slowly, gaster breathing), starts from the `Sag` final pose with no blend: `SagIdle` cue ~3.9 s after the `Sag`,
  or the prop's `action` for the ant already lying since the cut. By `action` on the prop (starts at the cut) or by the cue `{"do": "action", "action": "Rise"}`.
- **Growing:** `grow` with `from` = initial size / `len` (1 cm -> 1.7 m: `"len": 1.7, "from": 0.006`), `dur` and
  `stagger`. An ant that grows must not walk while small (the step is computed for the final `len`).
- **`anthill`:** faceted earth mound with a dark crater and an entrance on the slope facing the camera. `len` = diameter
  (default 1.6), `h` = height (default 0.3 x diameter). `trail`: [[x, y], ...] draws the packed-earth trail leaving the
  mound (1 mm above the ground: the tip of the 1 cm ant's foot sinks 1 mm into it, no z-fighting). `scale_with_ants`: `true` grows along with the ants'
  `grow` (same factor), a number = final factor; without it, the mound does not change.
- **`macro` camera:** still at 0.15 m from the ground (`z` changes), lens 45 (`lens` changes), millimeter sway. For a trail
  of 1.2 cm ants, look from ~0.3 m: `{"preset": "macro", "at": [0, 0], "look": [0, 0.33, 0.004]}`; a person at
  ~1.5 m shows up only from the shin down.
- **Fixed along the way (build.py):** a path longer than the scene no longer speeds the piece up (before, the body ran the whole `path`
  to the end of the scene and the foot skated); now it walks at the planted-foot speed and stops wherever the scene ends.

## Known limits
- Only the stages above. City, farm and interior have no preset yet (Kenney fantasy-town and car-kit pieces are in the catalog); they
  only come in when a video asks for them.
- Pieces do not cross scenes: with `set: "same"`, redefine the piece in the new scene (same `at`). An animated piece (walking animal) restarts the action.
- Step matched to speed is by heuristic (stride = 0.9 x the animal's length, 1.5 m for people): it may skate a little.
- Kenney characters (`character-*`) have no skeleton: static only. Animated humans: `man`, `womancasual`, `animatedhuman`.
- `ual1-*` and `superhero-*` (Quaternius Universal) need retargeting and are marked `part`.
- Colors come from each pack's original materials (different styles between Quaternius stylized and Ultimate Nature).

## Known pitfalls (ants-human-size)
- `grow` twice on the same target breaks: the 2nd starts from the already changed scale. One `grow` per target.
- `grow` already holds `from` from the start of the scene (the piece does not appear large before the cue's `t`).
- `t: 0` in a cue is treated as false: use `0.01`.
- `span: "group"` + redeclaring the piece in a new scene duplicates it (a 2nd walker appeared). Declare once and cite the name in the cues.
- A persistent piece leaves with `vanish`.
- `Idle` is a standing pose: a piece that collapses (`Sag`) needs its own rest action (`SagIdle`).
- **Pose at the cut:** a piece with `span` does NOT return to `Idle` at the cut: the last NLA strip (`Sag`, `SagIdle`, `Rise`) holds the pose
  (HOLD_FORWARD) for the rest of the span. There is no need to repeat `{"t": 0.01, "do": "action", "action": "SagIdle"}` in each scene (repeating is
  harmless: `ant.play` ignores `SagIdle` on an ant that is already in `SagIdle`). Checked by body height (0.145 m at
  f983, 1263, 1435 and 1610). The "standing on the 1st frame" of scene 06 was a misreading, not data: from eye level, the old fallen pose (feet at
  1.16x of the support, knee up, the back one rose 0.22 L) looked like a standing ant. The fallen pose now spreads the legs
  (`SAG_SPREAD` 1.36 in the middle and 1.45 at the back, front foot to the side, knee outward: rises up to 0.1 L).
- **`Sag` impact:** the body hits the ground 2.2 s after the cue (`SAG_IMPACT`; the gaster 0.08 s later). `shake` and `dust` go at
  `t` of the `Sag` + 2.2 (e.g. `Sag` at 1.2 -> impact at 3.4).
- The panel counter only shows integers with a thousands separator ("2,665,928 x"); `unit` up to 8 characters, `panel_rows` value up to 14 and label up to 26 (lint warns). A counter that changes per frame has no tick per value (`sfx.py` limits it to 1 tick per 0.6 s).
- The safe-area check uses the targets of ALL cues: a tiny `grow` piece with lens > 50 fails the macro.
- `blender --frames A-B` redoes only the stretch (a scene with the same duration keeps the following frames).
- A scene with `on_screen` shows only the title for the whole scene; the `text` disappears (lint warns).
